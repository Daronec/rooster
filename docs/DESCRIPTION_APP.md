Описание проекта.

Экран SPLASHSCREEN
- Логотип Rooster
- Слоган "Не дадим пропустить важные дела"
- Картинка "Петух на фоне усадьбы"

Экран СПИСОК ЗАДАЧ
- Список созданных задач разделенный по группам. Группа это созданный ранее 
  список для задач на экране со списком задач.
- Каждая группа задач разбита на две части, выполненные задачи не 
  выполненные задачи. 
- Задача в группе задач имеет чекбокс для отметки выполнения задачи, 
  заголовка задачи
- Кнопка создания задачи
- Группа может разворачиваться и сворачиваться. 
- У каждой группы отображено её название указанное при создании списков задач

Экран СОЗДАНИЕ ЗАДАЧ
 - Поле ввода названия
 - Поле ввода описания
 - Открытие календаря и выбор даты исполнения задачи
 - Выбор времени исполнения задачи, время начала исполнения, дата окончания 
   исполнения или выбрать весь день.
 - Включение уведомления (Нет, В день, за 1 день, за 2 дня, за 1 неделю, 
   установка пользователем нужного дня и времени уведомления)
 - Постоянное напоминание (выбрать время напоминания и дни недели)
 - Выбор приоритета (Высоки, средний, низкий, нет)
 - Выбор тэга
 - Выбор списка (создается заранее на экране списков)
 - Добавление изображения
 - Кнопка сохранения задачи
 - Назначить пользователя на задачу как исполнителя или наблюдателя

Экран СОЗДАН СПИСКА
- Поле создания списка
- Выбор цвета списка кружками. Первый кружок отменяет выбор цвета, последний 
  кружок открывает диалог для выбора пользовательского цвета с помощью rgb 
  слайдеров.
- Копка Крестик чтобы отменить создание и закрыть экран, кнопка Галочка чтобы 
  сохранить список.

Экран НАСТРОЙКИ
- Выбор темы (темная, светлая, системная)
- Выбор цветовой схемы (предоставить на выбор набор из нескольких палитр 
  цветов, найди самые популярные наборы палитр цветов и возьми 10)
- Включение всех уведомлений (уведомления о предстоящей задаче. о выполнении 
  задачи)
- Выбор звука выполнения
- Включение вибрации
- Кнопка поделиться приложением
- Кнопка открытия окна обратной связи
- Кнопка открытия экрана О приложении (экран с информацией о приложении)
- Кнопка для доната

Экран ПРОФИЛЬ
- Аватарка пользователя + редактирование
- Имя и фамилия
- Электронная почта
- Статистика выполненных задач
- Добавленные друзья для управления общими задачами
