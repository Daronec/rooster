## Этап E1 — Стратегия и детекция (domain + data)

### Domain

- [x] Ввести enum (или эквивалент) **`AuthBackendStrategy`**: `firebase`, `huawei`, `offlineOnly` (п. 1.3 плана).
- [x] Добавить контракт **`IAuthEnvironmentProbe`** (или узкие порты): методы/сущности для сигналов без зависимостей от Flutter UI.
- [x] Реализовать **чистую функцию/сервис выбора стратегии** по правилам п. 1.2 (вход: `firebaseAvailable`, `gmsAvailable`, `isHuaweiHmsDevice`, `hmsCoreUsable`, платформа → выход: `AuthBackendStrategy`).
- [x] Написать **unit-тесты** на логику выбора стратегии (все комбинации + iOS/desktop не трогаем правило GMS).

### Data (Android)

- [x] Ввести порт **`GmsAvailabilityPort`** (или имя по конвенции проекта) — «доступны ли рабочие GMS» (п. 1.1).
- [x] Реализовать **`GmsAvailabilityPort`** для Android через `GoogleApiAvailability` (или согласованный API), без вызовов из domain.
- [x] Ввести порт/реализацию **`HuaweiHmsEnvironmentPort`**: `isHuaweiHmsDevice`, `hmsCoreUsable` (эвристика производителя / пакет `com.huawei.hwid` / HMS API — по п. 1.1).
- [x] Для **iOS / desktop** вернуть предсказуемые заглушки (например, `gmsAvailable: false` не влияет на выбор; стратегия по плану).

## Этап E2 — DI и регистрация на старте

- [x] После **`Firebase.initializeApp`** и асинхронных проверок GMS/HMS **один раз** вычислить `AuthBackendStrategy` и передать в регистрацию scope (п. 4.4, 1.3).
- [x] Пробросить стратегию (или производный флаг) в **`AppScope` / `IAppScope`** для доступа из presentation без глобального синглтона.
- [x] При стратегии **Firebase**: зарегистрировать текущий набор (`FirebaseAuthGatewayImpl`, `FirebaseTaskSyncExecutor`, …) без изменения поведения (п. 2).
- [x] При стратегии **Huawei**: зарегистрировать тот же Firebase-auth путь, где уже принято (B1), плюс **явно** сохранить стратегию для UI и логов (п. E2 плана).
- [x] При стратегии **offlineOnly**: зарегистрировать **OfflineAuthGateway** (или аналог) и исполнитель синка без удалённого Firebase (п. 1.2).
- [x] В **debug** логировать выбранную стратегию и при необходимости версии/флаги GMS-HMS **без PII** (п. 6 плана).
