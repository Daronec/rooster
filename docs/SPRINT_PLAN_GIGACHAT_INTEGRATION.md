> 14 спринтов (14 недель) с поэтапным внедрением облачного AI-ассистента GigaChat.

---

## Чем GigaChat отличается от Llama on-device

| Параметр | Llama on-device | GigaChat (облако) |
|----------|-----------------|-------------------|
| Модель | Llama 3.2 1B/3B | GigaChat Pro (Sber) |
| Зависимость | Нет (локально) | Интернет обязателен |
| Качество | Базовое (1B) | Высокое (Pro) |
| Время ответа | 2–10 сек | 1–3 сек |
| RAM | ~1.5 ГБ | 0 (облако) |
| Приватность | Данные на устройстве | Данные у провайдера |
| Стоимость | 0 | Пакет API (Sber) |

**Преимущества GigaChat:**
- Качественные ответы (Pro модель)
- Нет нагрузки на устройство
- Поддержка русского языка на уровне native
- Интеграция с экосистемой Сбера

## Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|---------|-----------|
| Зависимость от интернета | Высокая | Высокое | Offline fallback, кэширование |
| Стоимость API растёт | Средняя | Среднее | Кэширование, оптимизация промптов |
| Rate limiting | Средняя | Низкое | Queue requests, exponential backoff |
| Задержки API | Низкая | Среднее | Streaming response, progress UI |
| Конфиденциальность данных | Средняя | Высокое | Анонимизация данных перед отправкой |
