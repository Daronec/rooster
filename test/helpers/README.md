# `test/helpers/`

Общие функции для widget- и integration-тестов (обёртка приложения, тема, локализация, тестовый роутер).

## Когда добавлять сюда код

- Одинаковая разметка/настройка повторяется **как минимум в двух** тестах — вынести в хелпер.

## Файлы

| Файл | Назначение |
|------|------------|
| [test_app.dart](test_app.dart) | `wrapWithAppTheme` — `MaterialApp` с `AppThemeData.lightTheme` для widget-тестов uikit/фич |

## Документация

- Каждая **публичная** функция или класс — краткий комментарий `///` (назначение, обязательные параметры, побочные эффекты) или описание в этом README со ссылкой на файл.
