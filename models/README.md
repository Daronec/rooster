# Llama 3.2 Model for Rooster

## Описание

Этот каталог содержит GGUF модель Llama 3.2 для on-device inference в приложении Rooster.

## Требования к устройству

| Параметр | Минимум | Рекомендуемо |
|----------|---------|--------------|
| RAM | 4 ГБ | 8 ГБ |
| Место на диске | 3 ГБ | 5 ГБ |
| ОС | Android 12+ / iOS 15+ | Последняя версия |

## Скачивание модели

### Шаг 1: Установка huggingface-cli

```bash
pip install -U huggingface_hub
```

### Шаг 2: Получение доступа на HuggingFace

1. Перейдите на [huggingface.co/meta-llama](https://huggingface.co/meta-llama)
2. Запросите доступ к Llama 3.2
3. Одобрите лицензию Meta

### Шаг 3: Скачивание модели 3B Q4_K_M

```bash
huggingface-cli download meta-llama/Llama-3.2-3B-Instruct-GGUF \
  llama-3.2-3b-instruct-q4_k_m.gguf \
  --local-dir ./models
```

### Альтернатива: скачивание 1B модели (для устройств с малой RAM)

```bash
huggingface-cli download meta-llama/Llama-3.2-1B-Instruct-GGUF \
  llama-3.2-1b-instruct-q4_k_m.gguf \
  --local-dir ./models
```

## Расположение

Скачанный файл `.gguf` должен находиться в:
```
rooster/models/llama-3.2-3b-instruct-q4_k_m.gguf
```

## Характеристики моделей

| Модель | Формат | Размер | RAM |
|--------|--------|--------|-----|
| Llama 3.2 1B | Q4_K_M | ~0.8 ГБ | ~1.5 ГБ |
| Llama 3.2 1B | Q5_K_M | ~1.0 ГБ | ~2 ГБ |
| **Llama 3.2 3B** | **Q4_K_M** | **~2.0 ГБ** | **~3 ГБ** |
| Llama 3.2 3B | Q8_0 | ~3.5 ГБ | ~5 ГБ |

## Troubleshooting

### Ошибка "Failed to load LLM model"
- Проверьте, что файл `.gguf` существует в `models/`
- Убедитесь, что файл не повреждён (проверьте размер)

### Ошибка нехватки памяти
- Закройте другие приложения
- Попробуйте модель 1B вместо 3B
- Используйте устройство с ≥ 8 ГБ RAM

### Приложение падает при запуске LLM
- Проверьте логи через `flutter logs`
- Убедитесь, что native library собрана корректно
- Попробуйте очистить кэш: `flutter clean`
