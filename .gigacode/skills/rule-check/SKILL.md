# Rule Verification Protocol

- If you can't recall all rules, you SHOULD say "Memory check failed: I lost context of some rules"
- If asked to refresh rules, you SHOULD read `.mdc` files
- When starting a new task, you SHOULD verify rule retention with "Rules in memory: [3 rule names]"
- For "rule check" queries, you SHOULD list currently retained rules
- You SHOULD NEVER list more than 3 rules in bullet points (without file extension)
- The 4th line MUST indicate how many additional rules are in memory
- You SHOULD list rules in order of oldest remembered first
