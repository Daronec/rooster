# План: Внедрение Llama 3.2 1B on-device в Rooster

## Цель
Добавить локальную нейросеть Llama 3.2 1B для решения простых задач (классификация, извлечение сущностей, категоризация) прямо в приложении.

## Контекст
- Приложение: Flutter (Rooster — Task Manager)
- Текущая архитектура: Clean Architecture, gateway pattern, Elementary
- Native infrastructure: отсутствует (greenfield для FFI)
- Платформы: Android (arm64-v8a), iOS
- Модель: Llama 3.2 1B Instruct Q4_K_M (~0.8 ГБ, ~1.5 ГБ RAM)
- Технология: llama.cpp через dart:ffi

---

## Этап E1: Подготовка инфраструктуры (native)

### E1.1. Структура native-кода
- Создать `native/llama_cpp/` — клон llama.cpp (git submodule)
- Создать `native/flutter_llm_bridge/` — FFI bridge header + implementation
- Создать `models/` — каталог для GGUF модели (README + инструкция по скачиванию)

### E1.2. Native FFI header
- Файл: `native/flutter_llm_bridge/llm_bridge.h`
- Экспорт функций: `llm_init`, `llm_generate`, `llm_free`, `llm_free_result`, `llm_get_info`

### E1.3. Native FFI implementation
- Файл: `native/flutter_llm_bridge/llm_bridge.cpp`
- Обёртка вокруг llama.cpp API
- C-compatible interface

---

## Этап E2: Android build configuration

### E2.1. Клонирование llama.cpp
- `native/llama_cpp/` → git clone llama.cpp, checkout стабильной версии

### E2.2. Настройка CMake для Android
- Файл: `native/llama_cpp/CMakeLists.txt` (или использовать существующий)
- Настройки: `-DLLAMA_NATIVE=OFF`, `-DLLAMA_AVX=OFF`, `-DLLAMA_FMA=OFF`, `-DLLAMA_F16C=OFF`
- Target: `arm64-v8a`, API 24+

### E2.3. Подключение в Gradle
- Файл: `android/app/build.gradle.kts`
- Добавить `externalNativeBuild` с CMake path к `native/llama_cpp/`
- Добавить `aaptOptions { noCompress("gguf") }`

---

## Этап E3: iOS build configuration

### E3.1. Создание Podfile

- Build Settings: C++17, libc++

## Верификация

### Как тестировать:
1. `flutter pub get` — проверить установку зависимостей
2. Собрать Android: `flutter build apk --debug` — проверить линковку native
3. Собрать iOS: `flutter build ios --debug` — проверить линковку native
4. Запустить на устройстве → открыть AI чат → отправить запрос
5. Проверить RAM через Android Studio Profiler / Xcode Instruments

### Ожидаемые результаты:
- Сборка проходит без ошибок
- Модель загружается из assets/cache
- Генерация работает за 2–10 секунд
- UI корректно отображает диалог
- Нет утечек памяти при repeated generate
