# Plan: Инструкция по внедрению Sber ID в Rooster

## Цель
Создать инструкцию в `docs/SBER_ID_AUTH_INTEGRATION.md` по добавлению авторизации через Sber ID.

## Контекст
- Приложение: Flutter (Rooster — Task Manager)
- Текущая авторизация: Appwrite (Google, Apple, email/password, Huawei ID)
- Архитектура: Clean Architecture, IAuthGateway pattern
- Дополнительные пакеты не нужны: app_links и appwrite уже есть

## Шаги
1. Изучить текущую архитектуру авторизации
2. Описать регистрацию в Sber Developer Portal
3. Описать настройку OAuth в Appwrite Console
4. Описать подготовку Flutter-проекта (Android/iOS манифесты)
5. Предоставить код для SberIdAuthGatewayImpl
6. Предоставить код для UI-виджета кнопки Sber ID
7. Добавить строки локализации (ru/en)
8. Описать тестирование и критерии приёмки
