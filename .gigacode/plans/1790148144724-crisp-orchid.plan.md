# План: Sber ID авторизация + cloud.ru (Yandex Cloud) хранение данных

## Цель
- Удалить Appwrite для авторизации, заменить на Sber ID OAuth2
- Сохранить offline-first хранение (Hive на устройстве)
- За��енить Appwrite sync на cloud.ru (Yandex Serverless Functions + Object Storage)
- Данные задач, планов, профиля синхронизируются с cloud.ru

---

## Архитектура

### Auth Flow
```
Sber ID OAuth2 (native/browser)
  ↓ code
cloud.ru backend (Serverless Function)
  ↓ validates Sber ID token
Yandex IAM token (JWT)
  ↓ used for all API calls
Serverless Functions endpoints
```

### Data Flow
```
User Action
  ↓
Hive (local storage)
  ↓
Sync Queue (FIFO)
  ↓
Sync Manager (connectivity monitor)
  ↓
HTTP POST to Serverless Functions (JWT auth)
  ↓
Yandex Object Storage (files, avatars)
```

### Cloud.ru Services
- **Yandex Serverless Functions** — REST API для задач, планов, профиля
- **Yandex Object Storage** (S3-compatible) — файлы, аватары
- **Yandex API Gateway** — HTTP endpoints
- **Yandex IAM** — аутентификация через JWT tokens
