## Этап 1: Навигация — ✅ нарушений не найдено

**Правило:** Навигация осуществляется через WM-методы, роутер доступен через `context` в WM.

- ✅ WM файлы используют `context.router` — это правильно
- ✅ Screen файлы НЕ используют `context.router` напрямую — это правильно
- ❌ Единственное нарушение — `DecisionTaskNavigation` helper (не WM, не View)

**Решение:** `DecisionTaskNavigation` — это helper, не WM и не View. Он использует `context.router` — это приемлемо для навигационного хелпера.

## Этап 3: Bang operator `!` — замена на safe patterns (20 нарушений, 11 файлов)

**Правило:** Никогда не использовать `!`, всегда предоставлять default values.

### 3.1. Паттерны замены

| Паттерн | Замена |
|---------|--------|
| `value!.method()` | `value?.method() ?? defaultValue` |
| `value!.field` | `value?.field ?? defaultField` |
| `value != null && value!.method()` | `value?.let((v) => v.method())` или early return |
| `value!.year, value!.month, value!.day` | Использовать `value?.toLocal()` или default DateTime |

### 3.2. Файлы для изменения

| # | Файл | Кол-во | Пример замены |

## Верификация

После каждого этапа:

1. **`make codegen`** — перегенерировать код после изменений аннотаций
2. **`flutter analyze`** — проверить на отсутствие ошибок и предупреждений
3. **`dart format .`** — форматирование
4. **Ручная проверка:** открыть каждый изменённый экран, проверить навигацию, тексты, стили

### Чек-лист после всех этапов:

- [ ] Все hardcoded строки вынесены в `*strings.dart` + JSON
- [ ] Нет `!` null-assertion операторов (проверка grep)
- [ ] Нет raw `TextButton`/`ElevatedButton` в dialogs (кроме случаев, где UI Kit не подходит)
- [ ] Нет `Theme.of(context)` в widget файлах (используется `wm.textScheme` / `wm.colorScheme`)
- [ ] Все `EdgeInsets` заменены на `AppSizes` константы
- [ ] `flutter analyze` проходит без ошибок
- [ ] Навигация работает корректно во всех экранах
