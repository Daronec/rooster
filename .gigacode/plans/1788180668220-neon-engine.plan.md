# План реализации: Llama 3.2 On-Device LLM Integration

> Реализация локальной нейросети Llama 3.2 (1B) для простых задач прямо в приложении Rooster.

---

## Обзор реализации

**Цель:** Добавить on-device LLM (Llama 3.2 1B) через FFI + llama.cpp с UI виджетом чата.

**Архитектура:**
```
Presentation (AiChatScreen)
  ↓ Domain (ILocalLLMGateway)
  ↓ Data (LocalLLMGatewayImpl + FFI bindings)
  ↓ Infrastructure (llama.cpp native library)
```

---

## Этап 1: Подготовка инфраструктуры (Native Layer)

### 1.1 Клонирование llama.cpp

```bash
mkdir -p native/llama_cpp
cd native/llama_cpp
git clone --depth 1 https://github.com/ggerganov/llama.cpp.git
cd llama.cpp
git checkout b3339
```

### 1.2 Создание FFI bridge (C header + implementation)

**Файл:** `native/flutter_llm_bridge/llm_bridge.h`
- Интерфейс C-функций: `llm_init`, `llm_generate`, `llm_free`, `llm_free_result`, `llm_get_info`

**Файл:** `native/flutter_llm_bridge/llm_bridge.cpp`
- Обёртка над llama.cpp C++ API
- Инициализация llama_context из GGUF файла
- Генерация ответа с настройками temperature/max_tokens
- Управление памятью (malloc/free для FFI)

### 1.3 CMake конфигурация для Android

**Файл:** `native/flutter_llm_bridge/CMakeLists.txt`
- Сборка shared library (libllm_bridge.so) для arm64-v8a
- Зависимость: llama.cpp из `native/llama_cpp/`
- C++17, без AVX/FMA (мобильные CPU)

### 1.4 Подключение в Gradle

**Файл:** `android/app/build.gradle.kts` (изменить)
- Добавить `externalNativeBuild` с CMake path к `native/flutter_llm_bridge/`
- Настроить `aaptOptions.noCompress("gguf")` для модели

## Этап 3: Domain Layer

### 3.1 Контракт ILocalLLMGateway

**Файл:** `lib/features/ai/domain/gateways/i_local_llm_gateway.dart`

```dart
abstract interface class ILocalLLMGateway {
  Future<void> initialize(String modelPath);
  Future<String?> generate({
    required String prompt,
    int maxTokens,
    double temperature,
  });
  bool get isInitialized;
  String? get modelInfo;
  void dispose();
}
```

### 3.2 Реализация LocalLLMGatewayImpl

**Файл:** `lib/features/ai/data/local_llm_gateway_impl.dart`

### 4.2 Обновление AppScopeRegister

**Файл:** `lib/features/app/di/app_scope_register.dart` (изменить)
- В `createScope()`: попытка инициализации LLM
- Graceful degradation: если модель не найдена или ошибка — `localLLMGateway = null`
- Логирование статуса инициализации

```dart
ILocalLLMGateway? localLLMGateway;
try {
  final modelPath = await _findModelAsset();
  if (modelPath != null) {
    localLLMGateway = LocalLLMGatewayImpl();
    await localLLMGateway!.initialize(modelPath);
    logger.log('LLM initialized: ${localLLMGateway!.modelInfo}');
  }
} catch (e) {
  logger.log('LLM init failed: $e');
}
```

- [ ] Unit-тесты проходят

## Риски и митигация

| Риск | Митигация |
|------|-----------|
| Модель не помещается в RAM на старых устройствах | Проверка RAM при инициализации; предупреждение пользователя |
| Долгая первая загрузка (копирование модели из APK) | Копирование в cache dir асинхронно; прогресс-бар |
| Native library не собирается на CI | Docker image с NDK; fallback: feature отключена |
| Высокое потребление CPU/батареи | Ограничение max_tokens; кэширование контекста |
| Лицензия Meta Llama | Требует одобрения доступа на HuggingFace; проверка лицензии |
